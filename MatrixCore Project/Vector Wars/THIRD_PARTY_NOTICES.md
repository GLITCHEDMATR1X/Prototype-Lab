# Third-party notices

## pygame-ce

Vector Wars uses pygame-ce for windowing, input, audio, drawing, and presentation. pygame-ce is distributed under the GNU LGPL version 2.1 or later.

## SDL and related libraries

The Windows runtime produced by PyInstaller includes libraries used by pygame-ce. Their licenses are distributed with their respective projects.

## PyInstaller

PyInstaller is used only to assemble the portable Windows runtime and is not represented as original game code.

All Vector Wars game code and generated visual release material remain part of the GLITCHED MATRIX project unless otherwise noted.
