Fractured Nemesis - HoloVerse responder (Pass 282.65)

HoloVerse lists this game as a dimension on its own when the folder is anywhere inside
Prototype Lab or MatrixCore Project (up to three folders deep). It appears as a planet in
HoloSpace and in Gleebs' Dimension Archive.

It opens in its own window (launch_model external_child_process). HoloVerse waits, and when
this game closes HoloVerse comes back where you left it. ESC quits the game and returns to HoloVerse.

identity.json holds this reality's fixed id, so moving or renaming the folder keeps the link.
holoverse_link.py is optional: call report_to_holoverse(...) before exiting to send Gleebs a
result. Run on its own (python main.py) none of this is active.
Do not copy this project into HoloVerse/Dimensions.
