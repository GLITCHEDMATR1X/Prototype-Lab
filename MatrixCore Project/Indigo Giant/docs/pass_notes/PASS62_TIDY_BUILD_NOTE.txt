WHY
---
  - The game package: the modules have ordinary names (audio, hud, settings, controls, sky...).
    As indigo_giant.audio and so on they cannot collide with the main Steam game's modules
    when the game is folded in. Inside the package they import each other relatively.
  - paths.py is the only file that knows where assets, shaders, audio and fonts are. Before
    this, nine places each worked it out for themselves.
  - .dev/ starts with a dot because the Lab hub lists every .py file in a game's folder as a
    "version" you can pick on its cabinet, but skips folders starting with a dot. The cabinet
    offered 59 files; it now offers 30 (main.py plus the package), with main.py still the
    default.
  - cover.png: the hub shows a top-level picture whose name has "cover" in it.
