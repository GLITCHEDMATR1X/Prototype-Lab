# HoloShell Pass 01 — Windows Seamless Runtime Acceptance

Use HoloVerse 279 with HoloShell Pass 01.

1. In Gleebs Dimension Archive, use **Link Simulation** and select HoloShell `main.py`.
2. Confirm the archive entry reports HoloShell as native and shows the real hub-core preview.
3. Run HoloShell.
4. Windows must keep the same HoloVerse window: no second taskbar/window switch, no second ShowBase, and no display-size jump.
5. Confirm the real observatory loads: hub, artifacts, world lenses, generated HoloShell textures, Core interaction, and original HoloShell HUD.
6. Confirm HoloVerse display settings remain authoritative: window location, resolution, fullscreen mode, VSync/FPS behavior, HUD preference and cursor capture.
7. Test WASD + mouse look, Shift, Space, Control, LMB, E, Q, H, F1, T, and Core actions 1/2/3/5.
8. Press ESC. The normal HoloVerse menu must appear; use **Return to HoloVerse** if desired.
9. Re-enter HoloShell and press TAB. It must immediately return to HoloVerse.
10. After return, verify HoloVerse camera, FOV, background, lights, fog, HUD, mouse state and audio are restored with no HoloShell residue.
11. Re-enter HoloMap and HoloTactics once each to confirm prior native dimensions still work.

Reject the pass if HoloShell opens another window, applies its standalone PRC over the host, leaves fog/lights/UI behind, loses its real world simulation, or replaces the real game with an adapter-built placeholder.
