# HoloShell

HoloShell is a Panda3D first-person observatory/world simulation.

## Standalone

```bash
python main.py
```

## HoloVerse link

In HoloVerse's Gleebs Dimension Archive choose **Link Simulation**, select this folder's `main.py`, then use **Run Simulation**. HoloVerse 279+ mounts the complete HoloShell source into the existing host window.

## Controls

- WASD — move
- Mouse — look
- Shift — sprint
- Space / Control — contextual movement
- LMB — source fire/action state
- E — interact
- Q — Core secondary action
- H — HoloShell HUD
- F1 — HoloShell help
- F12 — HoloShell screenshot
- T — return to HoloShell hub
- 1 / 2 / 3 / 5 — existing Core actions
- TAB — return to HoloVerse when linked
- ESC — shared HoloVerse menu when linked; standalone HoloShell menu otherwise

No reduced HoloVerse replacement scene exists. `HoloShell.py` remains the game authority.
