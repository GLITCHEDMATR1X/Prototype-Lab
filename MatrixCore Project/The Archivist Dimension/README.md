# The Archivist — 3D Pass 07: Planetary Story Systems

This pass evolves the zero-gravity archive into a readable cosmic hierarchy.
Major records are presented as large planetary story worlds. Related written
records orbit them as moons, and linked simulations orbit as more cybernetic
satellites or ring-gates.

## Highlights
- Zero-gravity six-direction exploration preserved.
- Major story systems: MatrixCore, Afterlife of IO, Entropy, Utopia, Apocalypse, and Archive.
- Related records are grouped into local systems for easier discovery.
- Story length contributes modestly to orb size, so larger records feel more massive.
- Inclined 3D orbit planes and faint tracks make each family read as a real system.
- Linked simulations stand out as orbital gates/satellites.
- Nested HoloVerse-compatible dimension interface preserved.
- Drop-in soundtrack MP3 support preserved. Preferred: `assets/soundtrack.mp3`; fallback: any MP3 in `assets/audio/`.

## Controls
- **WASD** move relative to view
- **Space / Ctrl** vertical thrust
- **Shift** boost
- **E** read record
- **R** open record interface
- **F** reality bleed
- **Enter** enter linked simulation from interface
- **Esc** close active interface
- **F11** toggle fullscreen

## Notes
This pass is intended as the authority that follows Pass 06. It preserves the
Mind-archive atmosphere while making the record relationships far easier to
understand spatially.
