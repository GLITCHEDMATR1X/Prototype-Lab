VECTOR ARENA — AUDIO REPLACEMENT GUIDE

All bundled audio in this pass is original synthesized foundation/placeholder material.
You can replace any file while keeping the same filename.

Folders:
  assets/audio/music/       3 stereo combat loops
  assets/audio/ambience/    2 stereo ambience loops
  assets/audio/sfx/         mono gameplay/3D SFX
  assets/audio/transition/  dimension entry/exit cues

Important:
- Positional/3D SFX should remain MONO. Panda3D spatializes mono sources; stereo sources are not suitable for 3D positioning.
- Music and ambience may remain stereo.
- WAV files are currently 22.05 kHz / 16-bit PCM for a compact prototype footprint.
- Music rotates automatically and crossfades according to audio_profile.json/vector_arena_config.json.
- Missing audio does not prevent the arena from launching.
- --no-audio remains safe for standalone smoke tests.

PASS 06 ARENA-FAMILY NOTE
  Pass 06 adds no new mandatory audio files. Existing reconstruction,
  mutation, wave, Guardian, hazard, ambience and combat cues are reused so
  arena identity is primarily communicated through wireframe palette,
  geometry scale and existing transition audio rather than multiplying the
  sound library unnecessarily.
