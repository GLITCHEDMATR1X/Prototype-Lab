# Gleebs replaceable audio

Replace either WAV with your own asset while keeping the same filename, or edit `gleebs_audio.json`.

- `gleebs_purr.wav` — seamless mono radial loop owned by Gleebs.
- `gleebs_spark.wav` — short mono one-shot used by occasional physical-world damage sparks.

PCM WAV is recommended for predictable Panda3D playback. Keep positional sounds mono.
