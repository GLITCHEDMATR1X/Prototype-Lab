Afterlife of IO - HoloVerse responder

HoloVerse 282.50+ lists this game in Gleebs -> Dimension Archive on its own when the folder is
anywhere inside Prototype Lab or MatrixCore Project (up to three folders deep). Older HoloVerse
builds: use LINK SIMULATION and select this folder's main.py.

It opens in its own window (it is pygame; HoloVerse is Panda3D). "Quit" reads RETURN TO HOLOVERSE
while launched from HoloVerse, and the game leaves HoloVerse a small result on the way out
(Memory Guardians defeated, campaign complete). See holoverse_link.py.

identity.json holds this reality's fixed id, so moving or renaming the folder keeps the link.
Do not copy this project into HoloVerse/Dimensions.
