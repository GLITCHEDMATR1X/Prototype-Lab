# Actual Game Capture Correction

The previously linked `space_side_by_side.png` and `space_highlight.png` files were generated by the Pillow comparison self-test. They contained geometric test shapes and were not Entropy gameplay screenshots.

This correction adds `CAPTURE_ACTUAL_GAME.bat`, which:

- launches the real `space_core.py` test suite;
- captures the game's fixed 1920x1080 virtual canvas;
- requires `space.png`, `cockpit.png`, and `interior.png`;
- rejects 640x360 self-test images;
- rejects blank or placeholder-like captures using color, contrast, and tonal-range checks;
- writes `gameplay_capture_validation.json` beside the screenshots.

The comparison self-test remains useful for testing image-difference math, but it is no longer presented as gameplay proof.

## Container limitation

The current container cannot install `pygame-ce` from its restricted package mirror, so the actual Entropy runtime could not be launched here. The corrected Windows script installs the runtime and performs the real capture on the user's machine.
