Entropy Pass 28 state-aware music folder.

MCF24.mp3 is the original user-supplied expedition theme and is intentionally left unchanged.
Generated score loops:
- score_home_signal.wav
- score_ship_recovery.wav
- score_collapse_pressure.wav
- score_gleebs_link.wav

All generated loops are deterministic 48 kHz stereo PCM and can be regenerated with:
  python tools/generate_score_loops.py --force

Runtime routing is campaign/collapse-driven; this folder is no longer treated as a sequential playlist.
