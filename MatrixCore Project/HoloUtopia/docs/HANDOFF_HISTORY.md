# HoloUtopia Pass 78 - Town Focus Vertical Slice Handoff

## Current state

The Town Focus vertical slice is now a playable autonomous city loop:

1. Start in the full city overview.
2. Click a town/district signal or building to enter Town Focus.
3. The selected town is isolated and framed with a tighter tilt-shift camera.
4. Local civilians, events, routes, activity clusters, need beacons, and health reports appear only for the focused town.
5. The watcher can inspect event diamonds, citizens, route trails, activity clusters, and buildings.
6. Selected events accept watcher nudges with 1-4.
7. Event pressure/outcomes, NPC memory, town consequences, health reports, selected detail, follow targets, and orders persist in runtime_state.
8. ESC / Backspace / 0 returns to the full city overview.

## Camera rules

- Full City Overview pivots around the center of the whole city.
- Town Focus pivots around the center of the selected town.
- RMB / Arrow keys orbit around the active pivot.
- Mouse wheel zooms in/out around the active pivot.
- WASD pans the active pivot.
- Town Focus should stay tighter than the full city and avoid showing unrelated districts or broad editor guide shapes.

## Persistence policy

Runtime session memory is stored at:

```text
data/database/utopia/runtime_state/town_focus_session_state.json
```

This folder is generated locally and should not be included in normal patch-only zips.

The generated runtime state is versioned and size-bounded. It quarantines corrupt, oversized, or incompatible save files instead of breaking launch.

Authored files remain the source of truth:

```text
data/database/utopia/citizens/
data/database/utopia/towns/
data/database/utopia/schedules/
```

Do not mutate authored schedules as part of runtime Town Focus behavior.

## PASS79 FIRST PERSON WALK MODE HANDOFF

Source: `PASS79_FIRST_PERSON_WALK_MODE_HANDOFF.md`

# HoloUtopia Pass 79 - First-Person Walk Mode Handoff

Pass 79 adds the first playable walking layer inside the existing Town Focus system.

## Current loop

1. Start in Full City Overview.
2. Click a district signal or building to enter Town Focus.
3. Press `Enter` or `P` to enter first-person walk mode inside the isolated town.
4. Walk with `WASD`, hold `Shift` to jog, and use RMB drag for mouse look.
5. Press `E` to interact with the crosshair target.
6. Press `ESC` to return to the tilt-shift Town Focus view.
7. Press `ESC`, `Backspace`, or `0` again to return to the full city overview.

## Interaction stack

First-person `E` reuses the existing Town Focus selection stack:

- local event diamonds
- activity clusters
- route/flow trails
- buildings
- citizens

It does not create a second disconnected interaction system.

## State policy

First-person player/camera position is stored per town in runtime state under:

`first_person_player_memory`

This is runtime/session memory only. It does not mutate authored schedules, town JSON, citizen schedules, HoloVerse routes, HoloCore routes, or artifact adapters.

## Performance rule

First-person mode only works inside the selected isolated Town Focus district. It does not enable full-city visible NPC simulation.

## Known next polish

- Better spawn point tuning per district.
- Better line-of-sight / nearest-target prompt.
- More readable first-person NPC movement.
- Optional low wall/building avoidance if needed later.
